Bucket names use 3–63 lowercase letters, numbers, and hyphens. Namespace names start with a lowercase letter and use lowercase letters, numbers, or underscores.

New table names: start with a lowercase letter; valid characters are a-z, 0-9, and underscores (_). Hyphens are converted to underscores.

2. Select Data files

Supported formats: Parquet, Parquet GZIP, XLSX, XLS, CSV, and TSV. The first upload defines a new table’s schema. Later uploads must match at least 50% of that schema after column-name normalisation; unmatched columns are ignored and missing target columns become NULL.

Healthcare sanitization is enforced before temporary S3 staging: names, DOB, phones, and home addresses are removed; identifiers are encrypted; age is banded; postal codes retain only two digits.

De-duplication

Choose this for every upload. The clean path avoids de-duplication work entirely; keyed mode lets you define or apply the table’s composite-key contract.
